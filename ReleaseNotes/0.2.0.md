# HandleScope 0.2.0

HandleScope 0.2.0 adds negotiated SessionDock compatibility without breaking
existing installations or clients.

## Compatibility

- The legacy `connection.json` document and `/v1/health` response are byte-shape
  compatible with v0.1.x clients.
- New clients can authenticate `/v1/metadata` and select a locally compiled v1
  or v2 adapter. The server never supplies executable endpoint paths or request
  schemas.
- The desktop app now lets you prefer Automatic (v2), v2, or legacy v1. Both
  protocols remain available, and the preference applies after the API restarts.

## Release synchronization

- Every release now includes an immutable compatibility manifest that binds its
  package, API executable, protocol list, policy, and capabilities.
- The installed API carries the same bounded runtime manifest so SessionDock can
  identify it without trusting a self-reported version.
- SessionDock remains a separate optional download. Automatic selection changes
  only its recommendation; installation or replacement still requires a clear
  user confirmation, and downgrades remain blocked.

## Safety

The compiled Roblox singleton policy, standard-user boundary, loopback-only
listener, bearer-token handling, dry-run plan binding, and executable trust
checks are unchanged. HandleScope still has no silent updater and does not
enable SessionDock integration unless the user explicitly opts in.
