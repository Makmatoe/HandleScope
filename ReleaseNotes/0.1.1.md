# HandleScope 0.1.1

This maintenance release fixes the SessionDock integration opt-in helper for
Windows PowerShell 5.1.

## Fixed

- Running `Enable-SessionDockIntegration.ps1` again now correctly reports that
  the minimal `{"enabled":true}` setting is already enabled instead of failing
  while reading a single property under strict mode.
- The build now executes a Windows PowerShell compatibility regression test
  covering enabled, disabled, extended, and missing SessionDock settings.
- Download verification now warns users to keep each release in a dedicated
  directory and reports a missing checksum entry separately from a true hash
  mismatch.

## Security and compatibility

The local API policy, loopback authentication, standard-user runtime boundary,
and released executable behavior are unchanged. HandleScope remains unsigned
and should be downloaded only from the canonical GitHub release and verified
using its SHA-256 manifest and GitHub artifact attestation.
