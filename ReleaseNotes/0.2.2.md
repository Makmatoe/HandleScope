# HandleScope 0.2.2

HandleScope 0.2.2 provides the reviewed SessionDock compatibility release. It
supersedes 0.2.1, whose package remained intact but whose external release
manifest contained a locale-formatted timestamp that SessionDock correctly
refused.

## Compatibility

- The legacy `connection.json` document and `/v1/health` response remain exact
  for v0.1.x clients.
- New clients authenticate `/v1/metadata` and select only a locally compiled v1
  or v2 adapter. Remote metadata cannot supply endpoint paths, request schemas,
  commands, or executable code.
- The desktop app lets you prefer Automatic (v2), v2, or legacy v1. Both
  protocols remain available after restart.

## Release synchronization

- The immutable external and installed-runtime manifests bind the package, API
  executable, protocols, policy, capabilities, source revision, and canonical
  UTC source timestamp.
- Release verification now reads the raw timestamp strings before PowerShell can
  coerce them into culture-dependent date objects.
- SessionDock remains a separate optional download. Installation or replacement
  requires explicit confirmation, and downgrade protection remains enforced.

## Safety

The standard-user boundary, loopback-only listener, bearer-token handling,
single-use dry-run plans, compiled Roblox singleton policy, and executable trust
checks are unchanged. HandleScope still has no silent updater and never opts in
to SessionDock integration without a user action.
