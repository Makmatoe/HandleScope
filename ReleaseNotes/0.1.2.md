# HandleScope 0.1.2

This patch makes the optional SessionDock setup shorter and corrects the
integration path after the SessionDock rename.

## Easier SessionDock setup

- `Install-HandleScopeApi.ps1` now accepts `-EnableSessionDock`, allowing API
  installation, immediate startup, optional per-user autostart, and explicit
  SessionDock opt-in in one command:

  ```powershell
  .\Install-HandleScopeApi.ps1 -StartNow -EnableAutostart -EnableSessionDock
  ```

- Installed scripts inherit no Windows download marker after, and only after,
  their bytes match the reviewed release manifest. PowerShell execution policy
  is not changed or bypassed.

## Canonical and safe settings migration

- The opt-in helper now writes the canonical
  `%LOCALAPPDATA%\SessionDock\handlescope.json` file.
- When the canonical setting is absent, the helper can copy only the exact
  minimal `{"enabled":true}` opt-in from the former `RobloxOne` directory.
- Canonical settings always take precedence. Legacy data is never modified or
  deleted and cannot overwrite a current setting.
- Existing non-minimal canonical settings still require an explicit `-Force`
  before replacement.
- Fresh writes and explicit replacements are atomic and fail closed if the
  target changes unexpectedly.

## Validation

Windows PowerShell regression coverage now includes fresh setup, safe legacy
copying, canonical precedence, explicit replacement, idempotence, conflict
rejection, and temporary-file cleanup. The API contract, restricted Roblox
singleton policy, standard-user boundary, and loopback credential model are
unchanged.
