# HandleScope 0.3.0

HandleScope 0.3.0 adds a native Windows setup executable so installation and
lifecycle commands work on systems where PowerShell script execution is
restricted. Run these commands from the extracted, verified release folder in a
normal, non-administrator terminal:

```powershell
cd .\HandleScope-0.3.0-win-x64
.\api\HandleScope.Setup.exe verify
.\api\HandleScope.Setup.exe install --start-now --enable-autostart
```

The same executable supports `start`, `stop`, `enable-sessiondock`, and
`uninstall`. Existing PowerShell lifecycle entry points remain available as
compatibility wrappers, but they are no longer the recommended installation
path.

## Compatibility and security

- The setup executable requests `asInvoker` and installs only for the current
  user; it never asks for administrator privileges or changes execution policy.
- Release manifest schema version 2 records the setup executable's fixed path,
  byte length, and SHA-256 digest. `CONTENTS.sha256` and the SPDX SBOM also bind
  the new executable; the runtime manifest advertises its native capability.
- `handlescope.setup.native.v1` lets SessionDock 2.9.0 and later use the native
  setup adapter after that separate release is published. SessionDock 2.8.x
  remains on its authenticated HandleScope 0.2.2 compatibility path.
- Setup is published without single-file compression to avoid an unnecessary
  packed-binary antivirus signal.
- Bounded source-only security-product metadata streams are tolerated without
  being trusted. Setup hashes and copies only unnamed file data, never copies a
  named stream, and requires staged and installed files to be stream-clean.

HandleScope 0.3.0 is not Authenticode-signed. Verification establishes that the
download matches the published GitHub release, but it does not create publisher
reputation or override Microsoft Defender, SmartScreen, Smart App Control,
AppLocker, WDAC, or organization policy. If protection blocks the file, do not
disable it or add a broad exclusion; use the verification guide and follow your
administrator's review process.
